# LEC09 Sonic 애니메이션 뷰어 PRD

## 1. 목표
`pico2d`로 `sonic-sprite.png`에 들어 있는 Sonic의 모든 동작을 보여주는 애니메이션 뷰어를 만든다. 한 동작을 5회 재생하고 마지막 화면을 1초간 유지한 다음 다음 동작으로 넘어간다. 마지막 동작까지 끝나면 첫 동작부터 계속 반복한다.

## 2. 산출물과 실행 환경
- 소스 파일: `Labs/LEC09/sonic_animation_viewer.py` **한 개**. 동작·프레임 정보도 이 파일 안에 둔다.
- 이미지 파일: 같은 폴더의 `sonic-sprite.png`. 원본 이미지는 수정하지 않는다.
- 라이브러리: `pico2d`.
- 창 크기: **1200 × 600 픽셀**. 프로그램 시작 시 `open_canvas(1200, 600)`으로 연다.
- 실행 위치가 달라도 이미지를 찾을 수 있도록 소스 파일이 있는 폴더를 기준으로 이미지 경로를 만든다.

## 3. 스프라이트 시트 분석
원본 이미지는 399 × 525 픽셀이고, 캐릭터 프레임의 폭·높이·간격이 일정하지 않다. 따라서 일정한 칸 크기로 나누지 않고 **프레임별 잘라낼 영역**을 기록한다.

1. Sonic의 연속된 자세를 동작별로 묶고 재생 순서를 정한다. 회전하거나 공 모양으로 변하는 장면도 애니메이션에 포함한다.
2. 각 동작에 속한 프레임을 순서대로 나열하고, 프레임마다 `왼쪽 좌표`, `아래쪽 좌표`, `너비`, `높이`를 기록한다. 필요하면 표시 위치 보정값도 함께 둔다.
3. 이미지 위쪽 제목, 아래쪽 크레딧과 다른 캐릭터 그림처럼 Sonic 동작이 아닌 영역은 프레임 목록에 넣지 않는다.
4. 이미지 편집기의 위쪽 기준 Y좌표를 사용할 경우 `아래쪽 좌표 = 525 - 위쪽 좌표 - 프레임 높이`로 바꾸어 `pico2d`의 잘라내기 좌표에 맞춘다.
5. 동작별 프레임 수는 목록의 실제 길이로 판단한다. 모든 동작에 같은 프레임 수를 가정하지 않는다.

코드에서는 동작마다 `이름`, `프레임 목록`, `재생 속도`를 관리한다. 프레임 목록에는 위 좌표·크기와 필요한 위치 보정값을 둔다. 실제 동작 이름과 프레임 수는 시트의 영역을 확인한 뒤 확정한다.

## 4. 재생 동작
- **재생 상태:** 현재 동작의 현재 프레임을 일정한 간격으로 다음 프레임으로 넘긴다. 마지막 프레임까지 끝나면 해당 동작을 1회 재생한 것으로 센다.
- **반복 횟수:** 같은 동작을 정확히 5회 재생한다. 5회째가 끝나기 전에는 다음 동작으로 바꾸지 않는다.
- **대기 상태:** 5회째 마지막 프레임을 화면에 그대로 보이게 한 채 1초간 멈춘다. 대기 중에는 프레임과 반복 횟수가 바뀌지 않는다.
- **다음 동작:** 1초가 지나면 다음 동작의 첫 프레임으로 이동하고 반복 횟수를 초기화한다. 마지막 동작 다음에는 첫 동작으로 돌아간다.
- **시간 처리:** `pico2d`의 시간 값을 이용해 프레임 전환과 1초 대기를 관리한다. 시작 속도는 초당 약 10프레임을 기준으로 하고, 실행 화면을 보며 동작이 자연스럽도록 조정한다.

## 5. 화면 표시와 종료
- 1200 × 600 화면의 중앙 부근인 `(600, 300)`을 표시 기준으로 삼는다.
- 캐릭터가 분명하게 보이도록 기준 자세의 높이가 화면 높이의 절반 정도인 **약 300픽셀 이상**이 되게 확대한다. 원본 비율을 유지하고 가장 큰 자세도 화면 밖으로 잘리지 않게 조정한다.
- 프레임별 크기가 달라도 캐릭터 위치가 불필요하게 튀지 않도록 공통 기준점과 프레임별 보정값을 사용한다. 점프처럼 동작 자체에 필요한 움직임은 유지한다.
- 창 닫기 또는 `Esc` 입력을 처리하고, 종료 시 캔버스를 닫는다.

## 6. 단계별 개발 및 커밋
| 단계 | 작업 내용 | 확인할 결과 |
| --- | --- | --- |
| 1 | 시트의 동작·프레임 좌표 조사 | 제목·크레딧을 제외한 Sonic 프레임 목록 완성 |
| 2 | 1200 × 600 창 생성 및 이미지 불러오기 | 이미지 경로 오류 없이 실행 |
| 3 | 프레임 하나 잘라 그리기와 확대 | 엉뚱한 영역 없이 선명하게 표시 |
| 4 | 첫 동작의 전체 프레임 재생 | 프레임 순서와 속도 확인 |
| 5 | 나머지 동작 추가 | 동작별 다른 프레임 수까지 재생 |
| 6 | 5회 반복과 1초 대기 구현 | 횟수·대기 시간이 정확함 |
| 7 | 전체 순환, 위치 보정, 종료 처리 | 모든 동작이 계속 반복되고 정상 종료 |

각 단계는 실제로 구현한 내용을 기준으로 더 잘게 나누어 **최소 20개의 의미 있는 커밋**으로 기록한다. 커밋 메시지는 변경 내용을 알 수 있게 한국어로 작성한다.

## 7. 완료 기준
- `sonic_animation_viewer.py`를 실행하면 1200 × 600 창이 열리고 같은 폴더의 시트가 로드된다.
- Sonic의 모든 동작이 빠짐없이 올바른 프레임 순서로 재생된다. 제목·크레딧이나 옆 프레임이 섞여 보이지 않는다.
- 각 동작은 정확히 5회 재생되고 마지막 프레임에서 1초 멈춘 뒤 다음 동작으로 넘어간다. 마지막 동작 이후에도 전체 순환이 계속된다.
- 크기가 다른 프레임도 화면에서 충분히 크고 자연스럽게 보이며 캔버스 밖으로 잘리지 않는다.
- 창 닫기와 `Esc`로 정상 종료되고, 실제 개발 과정이 최소 20개의 내용 있는 커밋으로 남아 있다.
